## 二、视频文案（可直接复制）

### 2.1 标题（选一，建议 A/B 各发不可行时取 A）

- **A（痛点型）**：手机上说能办，可她找不到那个入口｜我们做了一个只指一个按钮的 AI
- **B（差异型）**：会办事的 AI 不稀奇，敢在刷脸前停手的才稀奇
- **C（人物型）**：68 岁的她，第一次自己办完了低保复核

### 2.2 视频描述

```
她 68 岁，独居。社区说低保复核手机上就能办，
可她找了十分钟，没找到那个入口。

我们做了「随行帮办」：
她说一句话，AI 读懂她要办什么，
然后一次只指一个按钮——
「点这里」，高亮就在那个格子上。

走错了，它会说：这里是医保，这里没有低保，按返回，我带你重走。
要刷脸、要付钱、要验证码的时候，它会停手：
「这一步必须您自己按，我不替您做。」

不是告诉她在哪办，是告诉她手指点哪儿。

#AI未来挑战赛 #AI产品实现
```

### 2.3 置顶评论（引导互动，提升热度权重）

```
补充三个细节：
1. 表单 5 个必填项，系统按档案一键预填，老人只需要核对；
2. 连续点错 3 次，它会生成一段能直接念给 12345 的话术；
3. 断网也能用——决策由本地流程引擎给出，大模型只负责把话说得像人话。
```

## 三、产品创意阐述（500 字以内，报名系统用）

> 需求：说明场景设定、与 AI 的结合点、创意亮点。以下 486 字。

```
【场景设定】
低保对象每半年要办一次资格复核。线上明明能办，但一位 68 岁独居老人要完成：在 12 宫格里找「民政服务」、在 24 项列表里翻到第 18 项、读完三段须知、填 5 个必填格、通过人脸核验、确认风控弹窗。任何一步走错，都没有人告诉她错在哪。子女电话里说不清「那个蓝色按钮」是哪一个，热线看不到她的屏幕，教程视频和她手机上的版本还不一样。

【与 AI 的结合点】
随行帮办不是问答客服，而是执行闭环的导航：AI 先把她的一句口语（「低保那个复核，今年还没弄呢」）翻译成结构化事项并复述确认，再读取当前屏幕，一次只指一个控件，同步语音播报；她点错时，AI 比对当前屏幕与应到屏幕，给出针对性解释而非一句「返回」——「这是临时救助申请，是给还没吃低保的人用的，您办的是复核」。

AI 承担四件事：口语意图理解、话术本地化（把「实名认证」说成「照一下您的脸」）、走错时的动态解释、口语填表（「我一个人，上月九百八」→ 人口 1、收入 980）。

【创意亮点】
一、决策归规则、措辞归模型：点哪个按钮由确定性流程决定，模型只负责怎么说，输出还要过结构校验与高危词过滤。所以断网能演示，模型抽风也不跑偏。
二、三个不做：涉及支付、人脸、验证码、授权协议的动作，系统主动停手，把决定权交还本人。对老年人，可撤销的麻烦优于不可逆的错误。
三、三级兜底：模型 → 规则 → 人工话术，任何一环失效，用户仍有下一步可走。
```

## 六、热度运营（合规范围内）

平台热度由播放、点赞、评论、转发综合计算，统计截止提交后 5 个自然日。

1. **发布时段**：晚间 19:00–21:30，老年议题在家庭场景下触达更高。
2. **前 2 小时**：请同学、家人真实观看并留言（禁止刷量，平台可识别）。
3. **评论区引导**：置顶评论抛出一个具体问题——「你家长辈办事时卡在哪一步？」——比「求点赞」更能带来真实互动。
4. **二次剪辑**：同一素材剪 30 秒版做二次发布，注意**同一作品不可在多个月赛重复参赛**，二次发布仅用于人气直通榜曝光。
5. **不要做的事**：不买量、不使用互赞群、不在标题堆砌无关热词——违规将取消资格。
