# 原创性与借鉴边界自查

> 这份文档回答一个问题：**如果评委怀疑「这是抄的」，我们拿什么当场自证。**
> 结论分三层说：代码层（可核验）、素材层（可核验）、概念层（必须诚实）。

## 一句话结论

**代码和素材是自研的，可以逐项核验；产品概念是组合创新，不主张发明了其中任何单项能力。**

后者必须主动说清——评委最反感的不是「你借鉴了」，而是「你假装没借鉴」。

## 三、概念层：诚实列出「哪些不是我们发明的」

这是最容易被追问的一层，先自己说完：

| 能力 | 已有产品/做法 | 我们的关系 |
|---|---|---|
| 读屏 + 指到某个控件 | Android 无障碍助手类工具、各家「屏幕朗读/自动化」工具；学术界有 GUI agent 研究 | **不是我们发明的**。我们做的是把它用在「老人办事」这个具体场景，并把坐标现算（`getBoundingClientRect` 语义对齐 `AccessibilityService` 的 `bounds`） |
| 反诈话术判别 | 国家反诈中心、银行 App 的风控提示 | **不是我们发明的**。我们的差别是**按行为特征加权**（「安全账户」45 分、「验证码」30 分、「别告诉家人」32 分），并且**场景词不计分**——避免「我跟儿子说转账」被误判 |
| 代办/协办 | 支付宝亲情账户、微信亲属卡 | **不同路线**。他们是「授权 + 代操作」，我们是**不交出账号的「在场」**：6 位协办码、10 分钟有效、只能发提示不能代按。`CollabHint` 类型里**根本没有 `controlId` 字段** |
| 材料清单 | 政务办事指南 | **不是我们发明的**。差别是把它做成「办前体检」，并区分「现在有效」和「办完还有效」（`expiresAt` vs `mustStayValidDays`） |
| 到期提醒 | 日历、各类提醒 App | **不是我们发明的**。差别是提醒带**后果**（`consequence` 字段必填：「逾期会产生滞纳金，超过 30 天可能停水」），且与技术动作绑定 |
| 屏幕模型驱动 UI | 服务端驱动 UI（SDUI）、设计稿转代码 | **不是我们发明的**。差别是同一份模型**同时**给渲染和 Agent 读屏用（ADR-0002），保证「Agent 以为的界面」和「用户看到的界面」不可能不一致 |

### 我们主张的原创性在哪

不是某个功能，而是**三条约束下落出来的行为**：

1. **决策归规则、措辞归模型**（ADR-0001）。
   所有「去哪、点哪、能不能按」由确定性规则算；模型只负责把结论说成老人听得懂的话。因此同一句话问十次，路径完全一致——这在通用 agent 上是做不到的，它们每次都会给你一点不一样的建议。

2. **不代按写进类型系统**。
   `CollabHint` 只有 `at / from / text` 三个字段，没有 `controlId`。这不是产品策略，是**数据层不存在代按这个动作**。任何想加代按的人，先得改类型、改契约、改测试——这就是「结构性拒绝」。

3. **三源交叉，只出一个动作**。
   当前屏幕（你在哪）+ 守护日历（你什么时候必须办）+ 家庭材料库（你手上有什么），三者交叉后只输出**一个**下一步。通用 agent 给你一段建议，我们给你一个按钮。

**一句话**：「我们不主张发明了读屏、反诈、代办中的任何一项。我们主张的是：把它们约束在『不代按、不编造、每次一样』这三条线内，长出了一个通用 agent 长不出来的东西。」

## 四、商标与合规：已清理，且有据可查

### 已修掉一处真实风险

**修改前**：手机屏标题写的是「闽政通 · 首页」（`src/shared/screens.ts:36`）。

这是**商标性使用**——把它当作自己界面的应用名，不属于「为说明问题而合理使用他人商标」。风险有二：法律上可能构成侵权/不正当竞争；观感上会让评委以为我们在复刻官方应用。

**修改后**：
- 界面标题统一为「政务服务 · 首页」等中性名称；
- 手机下方标注「演示模拟界面，非真实应用」；
- 代码里加注释说明为什么不写真实产品名，防止后人改回去。

### 现在的边界

- 文档中提及「闽政通」仅用于**比较说明**（「它终止于提交成功，我们接前后两段」），属于描述性使用，不做商标性使用、不做 logo、不做图标仿制。
- **不使用**任何官方 Logo、不复制官方配色方案作为识别标识（当前配色为自定）。
- 演示界面是**自建的仿真屏**，不是对真实应用的截图或 UI 复刻。

## 五、如果被质疑，当场怎么自证

| 质疑 | 当场演示 |
|---|---|
| 「这是不是套了个开源模板？」 | `cat package.json` 看依赖：只有 fastify/react/zod，无 UI 框架 |
| 「界面是不是抄的某产品？」 | 打开 `src/web/styles.css`：单文件手写，选择器全是本项目组件名 |
| 「图片哪来的？」 | `node scripts/capture.mjs` 现场跑一遍，十张图重新生成 |
| 「概念是不是抄 XX 的？」 | 翻到本文第三节表格，逐条说「这个不是我们发明的，我们的差别在第 N 列」 |
| 「你是不是在冒充官方应用？」 | 指手机下方那行「演示模拟界面，非真实应用」，并说明标题已中性化 |
