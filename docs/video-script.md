# 演示视频脚本 · 随行帮办

> 赛题要求：30 秒–3 分钟产品演示视频，须在快手发布并带话题 `#AI未来挑战赛` + `#AI产品实现`。
> 本文提供 **3 分钟主版本**与 **30 秒精简版**，以及拍摄执行清单。

---

## 一、叙事结构

评委在 3 分钟里只会记住一件事。所以全片只讲一句话：

> **别人告诉你在哪办，我们告诉你的手指点哪儿；要花钱、要刷脸、要验证码的时候，我们停手。**

结构：`痛点（45s）→ 介入（75s）→ 改变（45s）→ 边界与延伸（15s）`

## 四、拍摄执行清单

### 4.1 素材准备

- [ ] 产品运行在 `http://127.0.0.1:8787`，浏览器缩放 100%，窗口固定 1440×900
- [ ] 关闭系统通知、微信弹窗、输入法候选
- [ ] 演示用假数据确认：王秀兰 / 350102195804120023 / 13800006021（均为虚构）
- [ ] 提前预热模型通道（先跑一遍 `npm run smoke`，避免首次调用延迟）
- [ ] 录屏软件 60fps，1080p 以上；麦克风单独收音

### 4.2 实拍部分

- [ ] 老人演员（可由团队成员长辈或同学化装出演），服装朴素，环境为家庭客厅
- [ ] 补光：侧前方柔光，避免屏幕反光
- [ ] 手机屏幕内容用后期贴片替换，不要真拍屏幕（摩尔纹）
- [ ] 眼神特写至少 3 条备用

### 4.3 剪辑要点

- 字幕字号 ≥ 屏幕高度 4%，全片硬字幕（平台静音播放场景多）
- 关键句（「停手」「一次只指一个按钮」「走错了会拉回来」）加字重与色块强调
- 背景音乐选无版权曲库，音量压到人声的 30%
- 结尾留 2 秒品牌板，方便平台截帧做封面

### 4.4 AI 内容标注（合规必做）

按大赛要求，使用 AI 工具生成的内容须标注来源。成片在简介与片尾字幕中注明：

```
本片画面为产品实际操作录屏；片头/片尾动效由 [工具名] 生成；
配音由 [工具名/TTS] 合成；未使用 AI 生成人脸或他人肖像。
```

> 注意：若使用 AI 生成人物形象，须自行确认不侵犯肖像权，且不得生成明星脸或未授权 IP 形象。

## 五、拍摄顺序建议（省时间）

1. 先录屏（产品状态可控，一次可录多条）
2. 再拍实拍（需要场地与演员）
3. 最后配音（对着剪好的时间轴配，比先配后剪更贴）
